# Chidera Okeke Emmanuel — Portfolio Website

A clean, modern, and responsive developer portfolio website built for **Chidera Okeke Emmanuel** (IT Student & Digital Solutions Developer).

## 🚀 Features
- **Mobile-First Design**: Responsive across mobile, tablet, and desktop screens.
- **Glassmorphism & Dark Theme**: Aesthetic styling with smooth CSS glow animations.
- **Interactive UI**: Scroll-reveal animations, responsive mobile hamburger menu, and active link tracking.
- **GitHub Pages Compatible**: Fully static site requiring zero dependencies, build steps, or server backends.

## 🛠️ How to Edit & Customize

### 1. Change Personal Information
Open `index.html` and edit:
- **Name & Title**: Title and heading tags.
- **Profile Image**: Replace `src="https://images.unsplash.com/..."` on line 55 with your photo URL or local relative path (`assets/profile.jpg`).

### 2. Social Links & WhatsApp Number
In `index.html`, find the social icons inside the Hero and Contact sections:
- **WhatsApp**: Pre-linked to `https://wa.me/2347049623191`.
- **GitHub & LinkedIn**: Update `href="https://github.com/chidexconcept"` with your direct profile links.

## 🌐 How to Deploy to GitHub Pages

1. **Create a Repository**:
   - Go to GitHub and create a public repository named `portfolio` (or `chidexconcept.github.io`).
2. **Upload Files**:
   - Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. **Enable Pages**:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Branch**, select `main` and click **Save**.
4. **View Site**:
   - After 1-2 minutes, refresh to view your live portfolio website!
